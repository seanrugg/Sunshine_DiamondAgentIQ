# 3-minute demo

1. **The problem (20 s).** Sunshine's website handles registration. Nobody teaches the parents, new coaches and teen umpires the rules, so disputes start in the stands. The mission is life lessons for every kid, including kids facing challenges.
2. **Install (20 s).** Open the app on a phone, Add to Home Screen, turn on airplane mode. It still works.
3. **Parent (30 s).** Parent · "Can I tell the umpire he missed a call?" → *Umpire's judgment* stamp, the Little League rule that judgment calls can't be protested, the parent code of conduct, and a life lesson.
4. **Coach (30 s).** Coach · age 12 · "He threw 70 pitches today. When can he pitch again?" → 4 calendar days, computed in code. Show the Pitch Count tab with the exact date.
5. **18U honesty (15 s).** Pitch Count, age 17 → the app says Little League doesn't cover 17-18 and asks the board, instead of guessing.
6. **Player (20 s).** Player · "I made the last out. How do I get past it?" → coaching moment, one thing to practise.
7. **Live mode (25 s).** Airplane mode off: header pill turns *live*; same question gets a model-written answer that cites only the rules it was given.
8. **The pitch to leagues (20 s).** Swap `data/league/` and the house rules CSV and any rec league gets its own edition. Board fills in the blanks; nothing is invented.
