# 3-minute demo

1. **The problem (20 s).** Sunshine's website handles registration. Nobody teaches the parents, new coaches and teen umpires the rules, so disputes start in the stands. The mission is life lessons for every kid, including kids facing challenges.
2. **Install (20 s).** Open the app on a phone, Add to Home Screen, turn on airplane mode. It still works.
3. **Parent (30 s).** Parent · "Can I tell the umpire he missed a call?" → *Judgment + rule* stamp, Sunshine's rule that only the head coach discusses calls with the umpire, the fan-conduct rule, and a life lesson.
4. **Coach (30 s).** Coach · 13U · "He threw 70 pitches today. When can he pitch again?" → 4 calendar days under the Sunshine 13U rule, computed in code. Show the Pitch Count tab with the exact date.
5. **House rules (15 s).** Parent · 10U · "Can my kid wear cleats?" → no, sneakers or turf shoes on the Sunshine turf. Switch to 18U → cleats allowed at Walker-Grant. Same question, the league's own answer for each division.
6. **Player (20 s).** Player · "I made the last out. How do I get past it?" → coaching moment, one thing to practise.
7. **Live mode (25 s).** Airplane mode off: header pill turns *live*; same question gets a model-written answer that cites only the rules it was given.
8. **The pitch to leagues (20 s).** Swap `data/league/` (house rules, pitch tables, league info) and any rec league gets its own edition on its own rulebook. Nothing is invented: every answer cites the league's document or a rulebook source.
